## p-toy-p1
Учебная сеть получает две координаты точки и определяет её класс. Кружки — обучающие примеры, квадраты — проверочные. Выберите **LP**, **FT** или **LP → FT**: браузер обучит сеть и покажет, какие точки она классифицировала правильно. Сравните результат на кружках и квадратах. Кнопка «готовые признаки, случайная голова» возвращает исходную сеть.

Внутри сети один признак $z = b_1 x_1 + b_2 x_2$ и выход $vz$. Обучающие точки различаются по первой координате, проверочные — по второй.

## p-toy-note
Во время обучения вторая координата почти нулевая, поэтому $b_2$ почти не меняется. Полное дообучение может перевернуть первый коэффициент вместе с головой и потерять качество на второй оси. LP меняет только голову; LP-FT начинает с уже обученной головы.

```python
def set_trainable(model, top_blocks):
    body = model.base_model
    for p in body.parameters():
        p.requires_grad = top_blocks == 'all'
    if top_blocks != 'all' and top_blocks > 0:
        for block in body.encoder.layer[-top_blocks:]:
            for p in block.parameters():
                p.requires_grad = True
        if getattr(body, 'pooler', None) is not None:
            for p in body.pooler.parameters():
                p.requires_grad = True
    return model
```
