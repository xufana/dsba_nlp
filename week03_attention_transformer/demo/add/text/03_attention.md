## attention-intro
Сохраним состояния энкодера на всех позициях. На каждом шаге декодер сравнивает своё состояние с каждым состоянием источника. Обучаемая функция выдаёт оценки соответствия, softmax превращает их в веса, а взвешенная сумма состояний даёт контекст текущего шага.

<div class="equation"><span>$e_{t,i}=\mathrm{score}(s_t,h_i)$</span></div>
<div class="equation"><span>$α_{t,i}=\frac{\mathrm{exp}(e_{t,i})}{\sum_{j=1}^{S}\mathrm{exp}(e_{t,j})}$</span></div>
<div class="equation"><span>$c_t=\sum_{i=1}^{S}α_{t,i}h_i$</span></div>

$h_i$ — состояние энкодера, $s_t$ — текущее состояние декодера, $S$ — длина источника. Выходной слой использует состояние декодера и контекст. При следующем слове состояние декодера меняется, поэтому меняются и веса. Обе сети и функция соответствия обучаются по ошибке перевода.

## attention-note
Та же развёрнутая RNN, что в блоке 01. Без attention декодер видит источник только через последнее состояние энкодера. С attention на каждом шаге все $h_i$ смешиваются с весами $α_{t,i}$ в контекст $c_t$; толщина линии — вес. Контекст идёт в выходной слой вместе с $s_t$. Выберите шаг: состояние декодера другое, поэтому другие и веса. Оценки учебные, не обученные; это не лингвистическая разметка.

## code-rnn-attention
```python
scores = score(decoder_state, encoder_states)  # @scores
scores = scores.masked_fill(source_ids == pad_id, -torch.inf)
weights = scores.softmax(dim=-1)  # @weights
context = (weights[..., None] * encoder_states).sum(dim=1)  # @context
logits = head(torch.cat([decoder_state, context], dim=-1))  # @output
```

## q-context · pick
Почему при генерации следующего слова контекст источника может измениться, хотя энкодер повторно не запускается?

- [x] изменилось состояние декодера, по которому вычисляются веса
- [ ] изменились слова исходного предложения
- [ ] softmax каждый раз выбирает случайную позицию

> Состояния источника сохраняются. На новом шаге декодер вычисляет новые оценки соответствия и новую взвешенную сумму.

## alignment-intro
Матрицу весов можно рассмотреть: строка соответствует шагу перевода, столбец — позиции источника. Для обучения достаточно пар предложений; соответствия отдельных слов не обязательны. Большой вес показывает вклад позиции в данную взвешенную сумму. Сам по себе он не объясняет весь выбор выходного слова.

## q-pad · pick
Можно ли сначала сделать softmax по всем позициям, а затем просто обнулить веса PAD?

- [ ] да, получится то же распределение
- [x] нужно ещё перенормировать веса; проще исключить PAD до softmax

> Иначе часть вероятностной массы уйдёт на PAD, а сумма оставшихся весов будет меньше единицы. В каждом источнике должна остаться хотя бы одна разрешённая позиция.
