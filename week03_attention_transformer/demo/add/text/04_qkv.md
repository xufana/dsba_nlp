## self-intro
Теперь построим представление каждого токена через другие токены той же последовательности. Это self-attention: для каждой позиции вычисляем свой набор весов и собираем свой контекст. Рекуррентный перенос состояния для этого не требуется. Внутри слоя позиции можно вычислять параллельно.

Как определить, какую информацию собирать и что передавать? Из входных представлений $X$ тремя обучаемыми линейными преобразованиями получаем **Q** (queries, запросы), **K** (keys, ключи) и **V** (values, значения). Запрос позиции сравнивается с ключами доступных позиций. Полученные веса определяют, как смешать значения.

<div class="equation"><span>$Q=XW_Q,\hspace{1em}K=XW_K,\hspace{1em}V=XW_V$</span></div>

## qkv-note
Столбцы — токены, строки — шаги расчёта, как в рисунках Alammar (2018). Векторы q, k, v получены из x учебными матрицами (под катом), обучения здесь нет. Запрос выбранной позиции сравнивается с ключами всех трёх позиций; softmax даёт веса; выход z — смесь значений с этими весами. Смените запрос: меняются оценки, веса и z, а k и v остаются прежними.

## q-roles · sort
Сопоставьте тензор и его роль.

- Q → запрос позиции
- K → сравнение с запросом
- V → содержимое взвешенной суммы

> Оценки получаем из Q и K; смешиваем V. Раздельные преобразования позволяют обучать способ сравнения и передаваемое представление.

## calculation-intro
Скалярные произведения всех запросов со всеми ключами образуют матрицу $T×S$. В self-attention $T=S$. Делим оценки на $\sqrt{d_k}$, применяем маску, затем softmax **по ключам в каждой строке**. Результат умножаем на V.

<div class="equation"><span>$A=\mathrm{softmax}(\frac{QK^T}{\sqrt{d_k}}+M)$</span></div>
<div class="equation"><span>$Z=AV$</span></div>

$d_k$ — ширина запроса и ключа одной головы. При независимых компонентах единичной дисперсии дисперсия скалярного произведения растёт с $d_k$; масштабирование сдерживает этот рост. $M$ равно нулю на разрешённых парах и $−∞$ на запрещённых. Каждая строка должна содержать разрешённый ключ.

## code-attention
```python
scores = q @ k.transpose(-2, -1) / math.sqrt(q.size(-1))  # @scores
scores = scores.masked_fill(~allowed, -torch.inf)  # @mask
weights = scores.softmax(dim=-1)  # @weights
output = weights @ v  # @context
```

## matrix-note
Те же числа в матричной форме. Выделенная строка S, A и Z — расчёт выбранного запроса со схемы выше. В self-attention энкодера без PAD маска нулевая; в блоке 05 она станет нужна.

## q-values · pick
Зафиксируем Q, K и маску, но изменим V. Что изменится?

- [ ] веса attention
- [x] результат взвешенной суммы, а веса сохранятся
- [ ] ничего, V не участвует в результате

> Веса зависят от Q, K и маски. V участвует в следующем матричном умножении.

## code-qkv-example
```python
X = torch.tensor([[1., 0.], [0., 1.], [1., 1.]])
W_Q = torch.eye(2)
W_K = torch.tensor([[1., 1.], [0., 1.]])
W_V = torch.tensor([[1., 0.], [1., 1.]])
Q, K, V = X @ W_Q, X @ W_K, X @ W_V
A = (Q @ K.T / math.sqrt(2)).softmax(dim=-1)
Z = A @ V
```
