# Занятие 4 — практика

[Ноутбук](week04_practice.ipynb): классификация новостей, генерация на GRU и собственный причинный блок трансформера с языковой моделью.

Запускается сверху вниз на CPU. Недостающие зависимости устанавливаются первой ячейкой. Учебные подвыборки AG News и анекдотов DSBA лежат в `practice_data.json` рядом с ноутбуком. Сохранены seed отбора и SHA-256 исходных корпусов. В Colab файл загружается из ветки ADD-2026; для локального запуска положите его рядом с ноутбуком.

SVG-схемы из HTML занятий 1–3 вложены в ячейки вместе с PNG-копиями для просмотрщиков. Отдельно скачивать изображения не требуется.

Ноутбук проверяет совпадение attention с PyTorch, причинность блока и всей модели, конечность градиентов, исключение PAD из усреднения и loss. Выбор состояния модели идёт по проверочной части, итоговая оценка — по тестовой.

Обновить вложения после выгрузки схем из HTML, сохранив текст, код и результаты ноутбука:

```sh
python scripts/embed_notebook_figures.py week04_practice/week04_practice.ipynb --figures week01_text_representations/figures week02_language_modelling/figures week03_attention_transformer/figures
```
