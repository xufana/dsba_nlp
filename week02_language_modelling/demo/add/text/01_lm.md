## lm-intro

Хотим сгенерировать текст. Перебирать все возможные предложения неудобно: даже у короткого начала много продолжений. Попробуем писать по одному токену: после «кот» выберем «ест», затем продолжим уже «кот ест». Каждый новый выбор зависит от всего написанного контекста.

**Языковое моделирование** — задача оценивать вероятности последовательностей токенов. Для генерации будем обучать модель предсказывать распределение следующего токена по предыдущим. На одном шаге это **классификация по словарю**: вход — идентификаторы контекста, выход — V вероятностей. Выбранный токен добавляем к контексту и повторяем шаг до EOS.

## lm-formula

<div class="equation"><span data-f="distribution">${P(w_1,w_2,w_3)} = {P(w_1)} · {P(w_2|w_1)} · {P(w_3|w_1,w_2)}$</span></div>

Это **цепное правило вероятностей**, точное равенство: вероятность последовательности раскладывается в произведение условных вероятностей. Здесь каждый токен зависит от всего предыдущего контекста; завершение EOS тоже предсказываем.

## lm-note

Модель возвращает вероятности; правило декодирования выбирает токен. На следующем шаге префикс уже содержит сделанный выбор. EOS завершает последовательность.

## lm-detail

Имена задач зависят от уровня описания. Предсказание одного токена — многоклассовая классификация. Создание целого текста — генерация последовательности. Регрессии по числовым идентификаторам здесь нет: близость номеров токенов ничего не означает.

Ту же факторизацию используем в переводе, но каждое предсказание дополнительно обусловлено исходным текстом. Предсказание вероятностей и выбор полезного для человека ответа требуют разных проверок.

## q-lm · pick

На одном шаге модель предсказывает идентификатор следующего токена. Это регрессия, потому что идентификатор — число?

- [ ] да, минимизируем расстояние между номерами
- [x] нет, каждый токен — отдельный класс

> Классификация по V вариантам. Выходом модели служат оценки всех классов, а меткой — идентификатор правильного токена.

## q-chain · write

Зачем раскладывать вероятность текста в произведение вероятностей токенов? Что нужно уметь вычислять модели?

- условное распределение следующего токена
- вероятность каждого продолжения зависит от префикса
- одна модель применяется повторно

> Не нужна таблица всех возможных текстов: достаточно условных распределений на каждом шаге. Их произведение задаёт вероятность конкретной последовательности, включая её завершение.

## code-lm
```python
all_logits, _ = model(prefix_ids)
logits = all_logits[:, -1, :]  # @distribution
probabilities = logits.softmax(dim=-1)  # @distribution
next_id = probabilities.argmax(dim=-1)  # @choice
prefix_ids = torch.cat([prefix_ids, next_id[:, None]], dim=1)  # @append
```
