## rnn-intro

Рекуррентная сеть читает токены по порядку. На каждом шаге объединяет новый эмбеддинг с предыдущим скрытым состоянием. Одни и те же параметры используются на всех шагах; по состоянию вычисляем распределение следующего токена.

## rnn-formula

<div class="equation"><span data-f="state">$h_t = {\mathrm{tanh}(W_x e_t + W_h h_{t-1} + b)}$</span></div>

<div class="equation"><span data-f="head">$z_t = W_o h_t + b_o$</span></div>

Состояние имеет H координат при любой длине префикса.

## rnn-note

Внутри ячейки преобразуем эмбеддинг нового слова и предыдущее состояние, складываем результаты со смещением и применяем tanh. На развёртке читаем «кот» → «ест» → «рыбу»; после каждого слова получаем распределение следующего. Матрицы одни и те же, значения состояний разные.

Для одного текста эмбеддинг имеет форму [d], состояние — [H], распределение — [V]. Для пакета текстов: эмбеддинги [B, T, d], состояния [B, T, H], логиты [B, T, V].

## rnn-detail

Общие параметры позволяют использовать опыт разных контекстов. Вместо отдельного счётчика на каждый префикс модель обучает преобразование состояний. Фиксированное состояние сжимает информацию, поэтому доступ ко всем нужным деталям прошлого не гарантирован.

При обучении ошибка поздней позиции передаётся через предыдущие состояния. На длинной цепочке градиенты могут затухать или расти. Gradient clipping ограничивает слишком большой градиент; затухание он не исправляет.

## gates-intro

LSTM добавляет отдельное состояние памяти и обучаемые ворота: сколько сохранить и сколько записать. GRU смешивает предыдущее и предложенное состояния и управляет использованием прошлого. Ворота помогают обучать зависимости; бесконечной памяти они не дают.

## gates-note

В LSTM верхняя линия переносит память c: f оставляет часть старой памяти, i дозирует новый кандидат g, o управляет выходом h. В GRU отдельной линии c нет: r управляет вкладом прошлого в кандидат, z смешивает кандидат с прежним h.

σ — сигмоида: каждая координата ворот лежит между 0 и 1. Кружок × означает покоординатное умножение, + — сложение. У ворот σ — свои обучаемые матрицы и смещения для hₜ₋₁ и eₜ; у кандидата g в LSTM тоже. В GRU преобразования для кандидата показаны отдельными блоками. tanh на линии c применяется прямо к памяти.

## q-shared · pick

Что одинаково у шагов одной RNN?

- [ ] входной токен и скрытое состояние
- [x] обучаемые матрицы преобразований
- [ ] вероятности продолжений

> Параметры общие, данные и состояния меняются. Поэтому модель применима к последовательностям разной длины.

## q-memory · write

В каком смысле h хранит контекст? Можно ли по форме [B, H] заключить, что модель помнит все токены?

- состояние вычислено по предшествующим токенам
- размер состояния фиксирован
- сохранность нужной информации требует проверки

> Состояние зависит от префикса, но форма ничего не обещает о полноте памяти. Проверяем задачи с нужной длиной зависимости и ошибки модели.

## code-rnn
```python
class LanguageModel(torch.nn.Module):
    def __init__(self, vocab_size, dim, hidden):
        super().__init__()
        self.embedding = torch.nn.Embedding(vocab_size, dim)  # @embedding
        self.rnn = torch.nn.RNN(dim, hidden, batch_first=True)  # @state
        self.head = torch.nn.Linear(hidden, vocab_size)  # @head

    def forward(self, ids, state=None):
        x = self.embedding(ids)  # @embedding
        h, state = self.rnn(x, state)  # @state
        return self.head(h), state  # @head
```

## code-gates
```python
lstm = torch.nn.LSTM(dim, hidden, batch_first=True)  # @lstm
h, (last_h, last_c) = lstm(x)
```
