# Материал для ноутбука с генерациями

`03_prompt.md` — объяснение форматов запросов и вопрос о примерах в контексте.
`prompt_examples.json` — полные входы и продолжения GPT-2: CPU, float32, жадное декодирование, до 16 новых токенов. Ревизия чекпойнта записана в файле.

Пересоздать примеры из локального кэша Hugging Face, из корня репозитория:

```sh
.venv/bin/python week06_gpt/parked/generate_prompt_examples.py
```
